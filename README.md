🩺 VitaCure — Voice-Based Health Assistant

VitaCure is a simple yet smart voice and text-based health assistant built using Python, Tkinter, and Speech Recognition. It provides quick home remedies for common ailments like fever, cold, cough, and headache — all through an interactive chat-style interface.

🌟 Features

🎙️ Voice Interaction: Speak naturally, and VitaCure listens and responds with remedies.

💬 Manual Input: Type your symptoms if you prefer text instead of voice.

🧠 Smart Responses: Suggests appropriate remedies for common health issues.

🗂️ Prescription Generator: Saves your entire consultation history as a text-based prescription.

🎨 User-Friendly GUI: Simple, clean, and responsive interface built with Tkinter.

⚙️ Technologies Used

Python

Tkinter (GUI)

SpeechRecognition

Pyttsx3 (Text-to-Speech)

Datetime

🚀 How to Run
pip install speechrecognition pyttsx3
python vitacure.py
